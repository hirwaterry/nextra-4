# Stock Management System

Welcome to the Stock Management System documentation. This system is designed for educational institutions to efficiently track and manage their inventory.

## Key Features

- User authentication for secure access
- Item management for inventory control
- Stock-in and stock-out tracking
- Remaining stock calculation
- MongoDB integration with Mongoose
- Session-based authentication

## System Architecture

The backend follows a modular architecture with clear separation of concerns:

- **Models Directory**: Contains Mongoose schemas that define our data structure
- **Routes Directory**: Contains Express route handlers for our API endpoints
- **Configuration Files**: Store environment variables and server configuration

## Backend Components

The Stock Management System backend includes:

- User authentication system
- Item management
- Stock movement tracking
- Remaining stock calculation
- Data persistence with MongoDB
